# Streamable HTTP SSE Architecture Review

Deep dive into Streamable HTTP versus legacy HTTP+SSE transports. With Streamable HTTP, all requests route to a single endpoint. Server-Sent Events allow progress notifications to stream incremental tokens back to the caller while the JSON-RPC call is still active.
